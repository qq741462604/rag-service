#### 改造点1：IP地址解析

- **类型**：数据加工
- **描述**：将IP地址解析为城市、省份、国家
- **输入字段**：IP_ADDRESS
- **输出字段**：IP_CITY, IP_PRO, IP_COUNTRY
- **加工逻辑**：调用IP解析服务，将IP地址转换为地理位置信息

#### 改造点2：模型评分返回

- **类型**：数据加工
- **描述**：将模型评分结果添加到决策结果中
- **输入字段**：predict_rescale_score
- **输出字段**：scoreResult
- **加工逻辑**：根据评分匹配决策码值，返回决策结果

#### 改造点3：外调接口（如有）

- **类型**：外调模型接口
- **描述**：调用外部风控模型接口获取评分
- **接口地址**：http://example.com/api/risk-score
- **请求方式**：POST
- **请求参数**：

```json
{
  "customerId": "客户号",
  "trxAmt": "交易金额"
}
```

- **响应参数**：

```json
{
  "score": 15000,
  "riskLevel": "MEDIUM"
}
```
